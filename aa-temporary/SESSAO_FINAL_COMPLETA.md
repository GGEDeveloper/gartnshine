## 🐛 ISSUES RESOLVIDOS

### **Issue #1: Search API retornava 500 error**
- **Problema:** `Error: Incorrect arguments to mysqld_stmt_execute`
- **Causa:** `pool.execute()` com prepared statements não funcionava corretamente
- **Solução:** Mudado para `pool.query()` em todas as search queries
- **Status:** ✅ RESOLVIDO COMPLETAMENTE
- **Arquivos afetados:** `routes/api.js`, `routes/index.js`

### **Issue #2: MariaDB syntax incompatibility**
- **Problema:** `IF NOT EXISTS` não suportado para `ADD INDEX`
- **Causa:** MariaDB não aceita `ALTER TABLE ... ADD INDEX IF NOT EXISTS`
- **Solução:** `DROP INDEX IF EXISTS` antes de `ADD INDEX`
- **Status:** ✅ RESOLVIDO
- **Arquivos:** `sql/critical_indexes.sql`, `sql/critical_indexes_safe.sql`

## 🎓 LESSONS LEARNED

### **Technical:**
1. **MySQL2 prepared statements:** Use `pool.query()` instead of `pool.execute()` for complex queries
2. **MariaDB syntax:** Always use `DROP INDEX IF EXISTS` before `ADD INDEX`
3. **Nodemon reloading:** Sometimes requires manual `rs` command
4. **Shared hosting:** Connection pooling deve ser conservador (3 connections)

### **Design:**
1. **Design systems:** CSS variables são essenciais para consistency
2. **Component libraries:** Reusable components save massive time
3. **Inspiration:** Best-in-class products (Notion, Airbnb) are great references
4. **Mobile-first:** Always design for mobile primeiro

### **Process:**
1. **Planning:** Detailed specs accelerate implementation
2. **Modular approach:** Build in phases, test incrementally
3. **Documentation:** Document as you go (saves time later)
4. **Git commits:** Frequent, well-named commits are gold
