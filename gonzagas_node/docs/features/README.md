### Adicionar Nova Feature

Ao implementar nova feature:

1. **Criar ficheiro de documentação**
   ```bash
   touch docs/features/nome-da-feature.md
   ```

2. **Template básico**
   ```markdown
   # Nome da Feature
   
   ## Objetivo
   [Descrição breve]
   
   ## Implementação
   [Como funciona]
   
   ## Configuração
   [Settings disponíveis]
   
   ## Testes
   [Como validar]
   
   ## Troubleshooting
   [Problemas comuns]
   ```

3. **Atualizar este README**
   - Adicionar entrada no índice
   - Incluir status e link
