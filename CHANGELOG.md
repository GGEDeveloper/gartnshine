# Changelog

Todas as alterações notáveis neste projeto serão documentadas neste arquivo.

## [1.0.0] - 2025-05-25

### Adicionado
- Novo painel administrativo moderno baseado no template Star Admin
- Sistema de autenticação e autorização aprimorado
- Módulos para gestão de produtos, clientes, fornecedores e vendas
- Dashboard interativo com gráficos e estatísticas
- Layout responsivo com suporte a dispositivos móveis
- Sistema de permissões baseado em papéis (RBAC)
- Upload e gerenciamento de imagens
- Validação de formulários no cliente e servidor
- Sistema de notificações e mensagens flash

### Alterado
- Estrutura de diretórios para melhor organização do código
- Atualização das dependências do projeto
- Melhorias na segurança das rotas administrativas
- Refatoração do sistema de rotas

### Removido
- Código legado não utilizado
- Arquivos de layout antigos
- Dependências desnecessárias

### Corrigido
- Problemas de desempenho nas consultas ao banco de dados
- Bugs na autenticação de usuários
- Problemas de layout em dispositivos móveis
- Validação de formulários
